# Issue #17: private PRNG oracle and immutable golden vectors

This directory is verification infrastructure, not a package source or runtime
API. `oracle.mjs` is an independent number-based implementation of the
immutable
`xoshiro128ss-1.1/direct128-msb-rejection-1` Sequence Profile. It maps the four
canonical Seed words directly to Generator State, uses the xoshiro128** 1.1
transition, takes the most-significant bits for bounded rejection sampling,
and models Replay Token restart and Serialized Generator State resume.

`golden-vectors.json` is language-neutral literal evidence. It is intentionally
not generated by the checker and includes the canonical direct-Seed vector's
first ten raw words and first three successor states, bounds one, two, six,
eight, sixteen, and 100, a non-power-of-two bound, a forced rejection followed
by acceptance, and exact exhaustion after zero through four attempts. The
crafted rejection state is recorded as data so rejection and state advancement
remain reviewable.

Run the blocking oracle/golden check from the repository root:

```sh
node verification/issue-17/check.mjs
node verification/issue-17/check-boundary.mjs
```

The first command compares every computed word, candidate, attempt, state, and
structured sample result against committed literals. A changed or corrupted
corpus therefore fails instead of being silently regenerated. To audit a
candidate corpus without replacing the committed file, pass its path as the
first argument or set `DRDICE_GOLDEN_FILE`.

The checker also pins the canonical Seed, established ten-word/three-state
reference, profile identity, schema version, bound ceiling, and attempt ceiling
independently of both the oracle and JSON. It probes bound 101 and fuel 5 for
structured no-consumption failures.

The second command is tolerant of this pre-package branch. After the #16
workspace supplies `packages/prng` and `packages/dice`, it verifies that both
manifests have explicit root-only exports and allowlists, and that neither
package contains or declares the private oracle. The oracle's location under
`verification/issue-17` and its import-free source are checked by the first
command as well.

The canonical raw words, in lowercase hexadecimal form, are:

```text
00002d00 00000000 005a7080 04389d80 79199d9b
61963b24 4cb9b57a de9d7431 de458f35 fdce1a54
```

These fixtures are review evidence for later type-level implementation work;
the package APIs must consume the literals without importing this oracle.
